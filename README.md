# Village War resource pack

The resource pack for Village War, a private cooperative Minecraft campaign played by a small
group of friends. The server downloads it automatically when a player joins.

It contains only client assets: music and sound effects, item and creature models, textures and
interface art. All audio and textures are original and were generated for this game. No source
code, world data or server configuration is published here.

Download the pack from the [releases](../../releases) page. It targets Minecraft Java 26.3
(pack format 97).
